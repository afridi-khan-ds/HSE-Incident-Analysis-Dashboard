HSE Incident & Safety Performance Dashboard

## Project Overview
This project analyzes workplace health, safety, and environmental (HSE) incident data using Microsoft Excel and Power BI. The dashboard helps identify incident trends, assess severity, understand root causes, and monitor corrective actions.

Note:This project uses synthetic data for educational and portfolio purposes. It does not contain actual company HSE records.

## Tools & Technologies
* Microsoft Excel
* Microsoft Power BI
* DAX (Data Analysis Expressions)
* PivotTables
* Data Visualization

## Key Performance Indicators
* Total Incidents
* Near Misses
* Lost Time Injuries
* Total Lost Workdays
* High Severity Events
* Corrective Action Status

## Dashboard Features
* Monthly incident trend analysis
* Incident distribution by department
* Severity distribution
* Root cause analysis
* Interactive slicers for department, severity, location, event type, and action status

## Project Structure
* data — Dataset
* excel — Excel analysis workbook
* powerbi — Power BI dashboard
* screenshots — Dashboard screenshots
* documentation — Project documentation

## Key Insights
The dashboard is designed to help users identify incident patterns, highlight high-severity events, understand recurring root causes, and monitor corrective-action progress.




## Disclaimer
All data used in this project is synthetic and created solely for learning and demonstration purposes.
